HOW TO ADD YOUR MEDIA
=======================

1. SONG ("Twilight" by Evan — plays from the CD on the intro page)
   - Copy your audio file into this folder
   - Rename it to exactly:  twilight-evan.mp3
   - (mp3, m4a or ogg all work — but then update the <source src>
     in index.html to match your filename)

2. VIDEO (plays on page 2 — your recorded message)
   - Copy your video file into this folder
   - Rename it to exactly:  placeholder-video.mp4
     (or pick your own name and update the <source src> in index.html)

3. Restart the dev server (Ctrl+C, then `npm run dev`) so Vite picks
   up the new files — then rebuild/share with `npm run build`.

Nothing else to change. ❤️
